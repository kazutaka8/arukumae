## 外から取得するデータ

### 公図（地図XML）

| 項目 | 内容 |
|---|---|
| 中身 | 法務省「登記所備付地図データ」。長野県上水内郡小川村（市区町村コード 20588）の 2026年版（令和8年2月時点のデータ。2026年4月15日公開） |
| 入手先 | [G空間情報センターのデータセット `houmusyouchizu-2026-1-995`](https://www.geospatial.jp/ckan/dataset/houmusyouchizu-2026-1-995)。案内は[法務省のページ](https://www.moj.go.jp/MINJI/minji05_00494.html) |
| 取得した日 | 2026-11-02。画面からはログインが要ると案内されているが、CKAN の API で調べたファイルの URL からは、ログインなしで取れた（下のコマンド） |
| 置き場 | `data/raw/20588-1000-2026.zip`（38,194,275 バイト。SHA-256 `5f87f96c…7e322086`。中に地図ごとの zip が28個と、検索用の CSV） |
| 利用規約 | `data/raw/license.pdf`（同じデータセットにある「登記所備付地図データ利用規約」）。要点は下 |
| 使う地図 | `20588-1000-6`（区間の主な地図）、`-18`・`-19`・`-20`・`-28`（隣。`-19` は 2026-11-03 に足した）。案A の候補は任意座標系の `-1` |
| リポジトリに入れない理由 | 大きい（zip で 38MB、主の地図は展開すると約 170MB）。利用規約の上では再配布できるので、区間の周りだけを切り出した小さなファイルは、出典と「加工した」ことを書いて入れてよい |

取り直すコマンド：

```bash
# データセットの中のファイルと URL を一覧する（ログイン不要）
curl -s 'https://www.geospatial.jp/ckan/api/3/action/package_show?id=houmusyouchizu-2026-1-995' \
  | python3 -c 'import json,sys; [print(r["name"], r["url"]) for r in json.load(sys.stdin)["result"]["resources"]]'

# 2026年版の zip を落とす
curl -L -o data/raw/20588-1000-2026.zip \
  'https://www.geospatial.jp/ckan/dataset/d342bf3a-8bd7-4ce6-b38f-0e1c844d4ef8/resource/d51d8804-8d07-4147-858b-9ec0d2712c77/download/20588-1000-2026.zip'
```

利用規約の要点（自分の理解。全文は `license.pdf`）：

- 複製・公衆送信・加工は自由。商用利用もできる。使った時点で規約に同意したとみなされる
- **出典を書く。** 例：出典：「登記所備付地図データ 上水内郡小川村」（法務省）（https://www.geospatial.jp/ckan/dataset/houmusyouchizu-2026-1-995）（2026年11月2日に利用）
- **加工したものには、出典とは別に「加工して作成」と書く。** 国が作ったように見せない
- してはいけないことの1つに「他の情報と照合するなどして特定の個人を識別する行為」がある。この道具は登記の記録と突き合わせない
- データは明治から現代までの図面が元で、作られた時期によって精度が違う、と書かれている

ほかの形：G空間情報センターの「法務省登記所備付地図データ変換済」という組織が、公共座標系の筆を GeoJSON・シェープファイルに変換したものを CC BY で公開している（[`aigid-moj-20588`](https://www.geospatial.jp/ckan/dataset/aigid-moj-20588)。2026年版の GeoJSON もある）。任意座標系の地図は入っていない。今は使っていない

### 航空写真

- 国土地理院「地理院タイル」の全国最新写真（シームレス）。道具が表示するときにタイルを読みに行く。ファイルとしては持たない
- 出典の書き方：「出典：国土地理院（地理院タイル）」。[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)にしたがう。切り抜いたり線を重ねたりして加工したものは、出典とは別に「加工した」ことも書く（国土地理院が作ったように見せない）
- 印刷物（持って歩く地図の PDF）に入れてよいかは【未決】

### 別の年の航空写真（試し）

- 長野県林務部「空中写真（R5年撮影分 長野・北信地域）」。G空間情報センターのデータセット [`ortho-r5`](https://www.geospatial.jp/ckan/dataset/ortho-r5)。小川村は `09_小川村.zip`（約 1.4GB、図郭ごとの GeoTIFF 13枚、0.4m／画素、JGD2000 第VIII系）
- 区間は図郭 `B7-c0` の1枚に入る。zip を全部落とさず、HTTP の範囲指定でその1枚（約 140MB）だけを取った（`experiments/case_c/tiles/nagano/`、リポジトリには入れない）
- 利用条件：CC BY。出典の書き方は「長野県林務部による空中写真撮影成果のオルソ画像（令和5年度撮影）（https://www.geospatial.jp/ckan/organization/nagano-rinsei）」。利用者案内（2026年4月1日改訂）に「大部分が未加工のまま販売しない」「使用後は利用者の責任で適切に破棄する」とあるので、写真から作った画像は公開リポジトリに入れず、試しの後に消す。判定の結果（JSON）だけを残す
- 国土地理院の年度別の写真（`nendophotoYYYY`）は、舞台では 2022年度だけがあり、全国最新写真と同じ写真だった（2026-11-02 に確かめた）。道具では凡例と「設定」で年を選べる（2026-11-03）。2023 年度の一部には Landsat-8・GRUS の画像が混じり、地理院の一覧に別の出典の表記が求められている

### 森林の区域

- 林野庁「森林計画対象森林レイヤ」（国有林・民有林の区域、林班）。G空間情報センターのデータセット [`layer`](https://www.geospatial.jp/ckan/dataset/layer)
- 形式：ベクトルタイル（pbf、ズーム13〜16、`https://rinya-tiles.geospatial.jp/fr_layer_pbf_2025/{z}/{x}/{y}.pbf`）、ラスタタイル（webp、ズーム5〜16）、都道府県ごとの GeoPackage（長野県は `fr_layer_20_2025.7z`、約 55MB）。道具はベクトルタイルを読みに行くので、ファイルとしては持たない
- 属性：民国別（国有林・民有林）、林班、森林計画区、市町村、データ時点など
- 利用条件：公共データ利用規約（第1.0版）と「森林計画対象森林レイヤの利用規約」。出典を書く。区域は空中写真の判読などで縮尺 1/5,000 相当で作られたもので、現地・登記と一致するとは限らず、所有権や境界を証明するものではない、と規約にある（2026-11-02 に確かめた）

### 道路の名前・番号

- OpenStreetMap。区間の線と同じく `tools/make_section.py` の応答に入っている
- 出典の書き方：「© OpenStreetMap contributors」。データは [ODbL](https://www.openstreetmap.org/copyright) で提供されている

## 入れないもの

- 実在の人の情報（地権者の名前・住所、登記の記録）。この道具は登記の記録を扱わない
- 実在の軌跡図。デモの軌跡図は、区間の中心線から期間中に作る架空のもの
- API キーなどの鍵
