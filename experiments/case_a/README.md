# 案A の試し：座標のない公図を Claude が航空写真に合わせられるか

任意座標系の公図（図面の中だけの座標で、地図に重ならないもの）について、Claude に公図の線画と航空写真を見せ、「公図の点 ↔ 写真の点」の組を出させた（2026-11-03。spec §8.5・§16）。F4 を道具に入れるか決めるための、時間を区切った試し。

## 素材

- 公図：小川村の地図XML のうち任意座標系の `20588-1000-1`（大字稲丘、429 筆。ほとんどが山林の筆で、道 11・水 3）。`data/raw/xml/` に展開したもの（リポジトリには入れない）
- 航空写真：地理院タイル（全国最新写真、z17、約 1m／画素）。`tiles/` に写しを置く（リポジトリには入れない）
- Claude に送ったのは `out/map1.png`（公図の線画。白地に筆界、地番、北が上、画素の格子）と `out/photo.jpg`（写真に画素の格子）の 2 枚だけ。どちらも公開データで、案件名や座標は送らない

## 正解の作り方

同じ大字・地番の筆は公共座標系の地図に 1 つもなかった（はじめの見立てと違った）。-1 の地番（474〜1189）は -6 の地番の並びの隙間に当たり、
「地番の底」（枝番の前の数。537-1 と 537-2 など）が同じ筆が -6 に 19 ある。枝番違いの筆はふつう隣り合うので、その重心どうしからヘルマート変換（平行移動・回転・縮尺）を最小二乗で求めた。
**数十 m の誤差を含む粗い正解**（残差 RMS 35m、縮尺 0.83、回転 −1.8°。置いた先は区間の東 0.5〜1km）。Claude の組が「当たらずとも遠からず」かを測る物差し。

## やり直し方

```bash
.venv/bin/python experiments/case_a/match.py     # 粗い正解 → out/truth.json、out/map1_truth.geojson
.venv/bin/python experiments/case_a/render.py    # 公図の線画と航空写真 → out/map1.png、out/photo.jpg
.venv/bin/python experiments/case_a/run.py fable 1   # Claude に組を出させ、正解と比べる → out/run_fable_1.json
.venv/bin/python experiments/case_a/run.py sonnet 1
```

API キーはキーチェーンの `arukumae-anthropic-api-key` から読む。1 回あたり入力 4,800・出力 3,000 トークンほど（Fable で約 $0.2、Sonnet で約 $0.05）。

## 結果（3 回）

| 回 | 組 | 組ごとの、粗い正解とのずれ（m） | 組から求めた縮尺・回転（正解 0.83・−1.8°） | 公図の中心の置き場所の違い | 自己申告の確信 |
|---|---|---|---|---|---|
| Fable 1回目 | 3 | 17・31・35 | 0.82・−9.6° | 54m | 低 |
| Fable 2回目 | 4 | 13・120・230・45 | 1.43・−9.2° | 178m | 低 |
| Sonnet 1回目 | 3 | 217・298・240 | 0.93・2.4° | 253m | 低 |

- Fable は 2 回とも、公図の中央の「道と水路が接する所」（地番 802〜804 の辺り）を写真の谷筋の分岐（約 600,590）に当て、これは粗い正解から 13〜17m。**森ばかりの写真でも、手がかりになる 1 点は当てた**
- けれど残りの組はぶれる。2 回目は線画の目盛りを読み違えて縮尺を 1.43 とし、東の組が 230m ずれた。Sonnet は公図を写真の左の水田に重ねて、全部 200m 以上ずれた
- 3 回とも自分で「確信 低」と言い、所見に「確かめられる地物が乏しい」「別の資料で裏付けを」と書いた。**外しているときに外していると言える**のは使える性質
- 粗い正解そのものが ±35m なので、15〜35m の違いは「当たり」と「正解の誤差」を分けられない

## 分かったこと・決めたこと

- Claude の役目は、spec §8.5 の 5 のとおり**粗い当たり**（公図のどのかたまりが写真のどの辺りか、1 点の当たり）まで。仕上げの基準点は人が打つ。基準点を Claude に任せる作りにはしない
- もう 1 つ、**AI を使わない粗い合わせ**がある：任意座標系の地図の地番は、隣の公共座標系の地図の地番の並びの隙間に当たることがあり、枝番違いの筆の重心から ±35m で置けた。地番の並びは地図XML の中にあるので、道具だけで試せる
- 提出までの残りの時間では F4 を道具に入れず、**望のまま**にする（2026-11-03 に決めた）。試しの結果は spec §16 に書いた

## ファイル

| ファイル | 中身 |
|---|---|
| `match.py` | 地番の底の並びから粗い正解を作る。ヘルマート変換の最小二乗 |
| `render.py` | 公図の線画と航空写真を作る（画素の格子つき） |
| `run.py` | Claude に組を出させ、粗い正解と比べる |
| `out/truth.json` | 粗い正解（変換、使った組、残差） |
| `out/map1_truth.geojson` | -1 の筆を粗い正解で置いたもの（緯度経度。法務省の地図データを加工して作成） |
| `out/map1.png`・`out/photo.jpg` | Claude に見せた 2 枚。線画は「登記所備付地図データ 上水内郡小川村」（法務省）を加工して作成。写真は「出典：国土地理院（地理院タイル 全国最新写真）」を加工（格子と目盛りを重ねた） |
| `out/run_*.json` | Claude の返事と評価 |
| `tiles/` | 地理院タイルの写し（リポジトリには入れない） |
