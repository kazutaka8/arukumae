# アルクマエの印・ロゴ・バナー（試作。2026-11-04）

名前と見た目の決め。SVG はこのフォルダ。見え方は `preview.html`（`cd app && npm run dev` のあと `http://localhost:5173/@fs/<リポジトリ>/docs/brand/preview.html`）。

## 名前

- **製品名は「アルクマエ」のまま。** 「現地を歩く前に」が、道具のすること（下調べ）をそのまま言っている。
  日本の業務の道具にはカタカナ 4〜5 文字の名前が多く（勤怠・人事・会計の SaaS にも）、企業で使う名前として遊びすぎではない
- **説明の一行（タグライン）を添える：「輸送路の用地下調べ」。** 会社の文書や提出の概要では「アルクマエ ── 輸送路の用地下調べ」と並べる。
  「用地交渉支援ツール」とは**書かない**。この道具は交渉をせず、歩く前に「どの筆・どの木を確かめるか」を絞るところまで（spec §4）。
  交渉を支援すると読めると、地権者の記録を扱う道具だと取られる（扱わない、と公開している）
- 英字は `arukumae`（リポジトリ・URL）。ロゴには出さない

ほかに考えた名前（決めるときの材料）：

| 名前 | よい所 | 弱い所 |
|---|---|---|
| アルクマエ | 行為（歩く前）が名前。覚えやすく、何の道具か説明しやすい | 「軽い」と感じる人がいるかもしれない → 説明の一行で補う |
| フデサキ（筆先） | 「筆（土地）の先を見る」と「筆の先」の掛け。短い | 掛け言葉が伝わらないと意味が取れない。書道の用語と重なる |
| ミチシラベ（道調べ） | 直球で分かる | ありふれていて、同名のサービス・商標がありそう（確かめていない） |
| ルートヒツ（route + 筆） | 専門の道具らしい | 読みにくい。音が硬い |

商標は確かめていない（提出の前に J-PlatPat で「アルクマエ」を一度引く）。

## 印（アイコン）

2026-11-04 に決めた：**ブレードの軌跡図**（`make_mark.py` で生成。`mark.svg`・白地 `mark-light.svg`・赤 1 点 `mark-red.svg`）。

- 濃紺 #0f1b33 の地に 8px の薄い格子（製図の方眼）。ブレードリフターの「ブレードだけ」の軌跡図を真上から、幾何で描く
- 根元が半径 R の円（台車の軸の道）をたどり、ブレード（長さ Lb）は進行方向の後ろへ。先端は半径 √(R²+Lb²) の円を掃く。
  先端の円は箱に内接し（左・下・右に接し、最後のブレードの先端が上端）、軌跡は左 → 下 → 右 → 上と 270°
- ブレードは等角度に 10 本、根元が太く先が細い形の**枠線**。最後（いま）の 1 本だけ塗る（運送会社の軌跡図で、現在の車両だけ実線にする約束と同じ）。
  根元の円は細い完全な円。掃く面は白の 7%、先端の軌跡は細い線。色は白 1 色
- 赤 #b7262a は `mark-red.svg`（いまのブレードだけ赤。Koniplus のロゴの「離れて加わる 1 つ」）で、バナーに使う。道具の favicon とロゴは単色
- 16px では「濃い箱に白い渦」になり、形までは読めないが見分けはつく。32px から軌跡図と読める
- 経緯：道にピン → 黄色い筆 → Codex の案（回頭・かかり）→ 透視の道と帯 → 平面の軌跡図（色つき）→ 単色、の順に試し、
  途中の案は `try/`（a〜z の preview-*.html）に残してある。発注者の決めは「幾何学的に、単色で、軌跡図っぽく、本数は多め」

## 横ロゴ

- `logo-h.svg`（白地）・`logo-h-dark.svg`（濃い地）。印＋「アルクマエ」＋説明の一行
- 字はシステムの書体（Hiragino Sans / Noto Sans JP、太さ 600）。**配る版（PNG・PDF・動画）では字をパスにするか、PNG に書き出す**（相手の端末に書体がないと崩れる）

## バナー

- `banner.svg`（1200×630）。OGP（`index.html` の `og:image`）、GitHub の social preview、提出の概要の頭に。
  左に名前と一文「現地を歩く前に、かかる筆と木を洗い出す。」、右に道具の地図の見立て（筆の線・道・かかる筆の黄色・区切りの色・赤い印）
- 使うときは PNG に書き出す（`rsvg-convert` か、ブラウザで開いてスクリーンショット）。文字はシステムの書体なので、書き出しは Mac で
