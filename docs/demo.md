## 決まり

- **AI で作った実写風の映像は使わない。** 本物の現場と取り違えられるおそれがあり、細部も崩れやすい。実写は本物の輸送の映像（他人の素材。下の表）だけにし、あとは道具の画面と、画面の上の軌跡・伐採範囲の動きで見せる
- 実在の現場（舞台の小川村を除く）の映像・地名・事業名は出さない。開発者が試した自前の道の地名も出さない
- 地権者の名前は出さない（この道具は登記の記録を扱わない）
- 軌跡図は「架空」と画面に出す。距離標の値は、ストリートビューで読めたら実際の値、読めなければ「架空」と出す
- 数字は出典を字幕に添える。法令にふれることは「〜とされている」と言う。届出の要否は「目安。所管に確かめる」
- 期間中に作ったものだけを見せる（新規制作の決まり）
- API キーの画面（右上の「設定」）は録画に映さない。「この端末に記憶する」は外したまま

## 撮る手順

### 準備（録画の前日まで）

1. ブラウザの案件を見本に戻す（手順 1「見本に戻す」）。開発者の試しの案件が IndexedDB に残っていることがある。記録・距離標が空の状態から撮るので、残しておきたい案件は先に「保存する（JSON）」で落とす
2. 設定：API キーを入れる（「この端末に記憶する」は外したまま。録画に設定の画面を映さない）。判定は Sonnet 5.5、見直しは Fable 5.1 のまま。「別の年の写真も一緒に見せる」は見せない（時間が倍になる）
3. ブラウザは Chrome、窓は **1920×1080**（手順のパネルと一覧の列「左右」「森林」が両方見える。1100px 以下だと列が消える）。拡大は 100%。ブックマークバーは隠す。通知は切る。`npm run dev` の URL（localhost:5173）は映ってよいが、アドレスバーは隠せるなら隠す
4. **公図の自動取得（Overpass への市町村の問い合わせ）が落ちている時間帯がある。** 前日に一度通す。だめなら「または、公図（地図XML の zip）を落とす」で見本の zip を落として撮り、ナレーションを「市町村の zip を落とすと」に変える（`data/raw/` は入れていないので、手元に無ければ G空間情報センターから取り直す）
5. 録画は QuickTime（画面収録）か OBS。30fps。マイクは別に録り、あとで合わせる
6. 距離標の値は架空（12.0・12.5）と字幕に書く。案件名は「小川村 県道401号（見本）」、道路名は「小川長野線」のまま
7. 別撮りは iPad の Google Earth に KML を入れた画面（画面収録）だけ。Excel・PDF・作り方は動画の側で描く（下の「編集」）

手で操作して録らない。`~/dev/remotion/koniplus-videos` の `tool/record-arukumae.sh` が、開発サーバ（5174）を立て、Playwright のブラウザ（1920×1080）で上の「本番の流れ」をそのまま操作して録る（台本は `tool/arukumae/record.mjs`）。録り直しても同じ動画になり、場面の始まりの秒は印（marks）として自動で控えられる。擬似のカーソルを重ねるので動きが見える。

- 本番（`tool.mp4`）が無いあいだは試しの `tool-a.mp4`（手順 1〜2）と `tool-b.mp4`（手順 3〜7）で通しを見せる。判定の印が無い取りでは、その切り出しを飛ばして残りで埋める
- **Excel・PDF・作り方は別撮りせず動画の側で描く。** 一覧表は `list.csv` を表にして、持って歩く地図は `walkmap-01/02.png` をめくって、作り方は `git log`・テストの件数・`.codex-review/` の結果（`tool/sync-assets.sh arukumae` が `making.json` に集める）から描く。ターミナルを映さないので本名・パスが出ない
- 残る別撮りは iPad の Google Earth（`ipad.mp4`）と実写（`pexels-blade.mp4`）だけ。無いあいだは灰色の板に名前が出る
- ナレーションの音は `public/arukumae/audio/narration.m4a`（無ければ無音のまま）。出典とライセンスは `public/arukumae/audio/SOURCES.md`
- 印・ロゴは `tool/sync-assets.sh arukumae` が `docs/brand/` から写す（`public/arukumae/from-app/`）
- 書き出しは `npx remotion render arukumae-demo out/arukumae/demo.mp4`（メモリ 16GB なので、ほかの重い処理と同時にしない）
- 道具の画面は切り抜かず全体を映す（パネルと地図の関係が分かるように）。寄せるときは編集でなく道具の操作で
- 最後の出典は 6 秒以上止める

## 映像の素材（他人のもの）

**動画のファイルはリポジトリに入れない。** 大きいうえに他人の著作物なので、`public/arukumae/footage/` に置く。使う前に、ライセンスをもう一度ページで確かめる（変わることがある）。

主催者は提出した動画を宣伝などに使うことがあり、そのときクレジットが外れるおそれがある。だから**表示が要らない素材（Pexels・CC0）を優先**し、CC BY-SA（できた動画にも同じライセンスが及びうる）はなるべく避ける。
