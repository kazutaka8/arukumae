# アルクマエ デモ動画（3分）の筋と素材

## 決まり

- **AI で作った実写風の映像は使わない。** 本物の現場と取り違えられるおそれがあり、細部も崩れやすい。実写は本物の輸送の映像（他人の素材。下の表）だけにし、あとは道具の画面と、画面の上の軌跡・伐採範囲の動きで見せる
- 実在の現場（舞台の小川村を除く）の映像・地名・事業名は出さない
- 地権者の名前は出さない（この道具は登記の記録を扱わない）
- 軌跡図は「架空」と画面に出す。距離標の値は、ストリートビューで読めたら実際の値、読めなければ「架空」と出す
- 数字は出典を字幕に添える。法令にふれることは「〜とされている」と言う
- 期間中に作ったものだけを見せる（新規制作の決まり）

### 決めること（たたき台のまま。開発者が決める）

- **0:32〜0:55 を自前の KML でやるか、見本の KML でやるか。** 明日の試しで自前の KML が通れば、その録画のほうが「自前の道で動く」の説得力が強い。ただし地名・案件名が映るので、画面の案件名を「試しの道」のような架空にし、地図は寄りすぎない。通らなければ見本の `section.kml` で
- **声。** 自分の声か、読み上げか。自分の声なら台本（下）を一息で読める長さに切ってある
- **Overpass が落ちていたときの逃げ。** 0:32〜0:55 は本番の操作なので、落ちていれば「手で zip を落とす」で撮り、ナレーションを「市町村の zip を落とすと」に変える
- 2:40〜2:52 の「作り方」は、公式 FAQ の Q9（Claude Code をどう使ったか）に応えるための場面。削るならここではなく 2:05〜2:18 を短くする

## 撮る手順

### 準備（録画の前日まで）

1. 道具を「見本に戻す」で見本の状態にし、判定は見本の 80 区切りを消して**未判定**にしておく（手順 4 の「判定する」を本番で押すため。判定し直しは約 $0.6）
2. 設定：API キーを入れる（「この端末に記憶する」は外したまま。録画に鍵の画面を映さない）。見直しのモデルは Fable 5.1 のまま。別の年の写真は「見せない」（時間が倍になるため）
3. ブラウザは Chrome、窓は 1440×900（Pages のレイアウトが PC 幅になる。iPad の割り付けは別撮り）。拡大は 100%。ブックマークバーは隠す。通知は切る
4. 録画は QuickTime（画面収録）か OBS。マイクは別に録り、あとで合わせる
5. 距離標の値は架空（12.0・12.5 など）と字幕に書く。案件名は「小川村 県道401号（見本）」のまま
6. 別撮り：Excel で CSV を開く（列幅を整えてから）、PDF の索引図と 1 ページ、iPad の Google Earth に KML を入れた画面（画面収録）
7. 「作り方」の素材：`git log --oneline`、`docs/spec.md`、`.codex-review/spec-20261103-1638.md`（P0 の行）、`.codex-review/decisions.md`、`npm test` の出力

### 本番の流れ（1 回で通す。失敗したら場面ごとに撮り直す）

手順 1（KML を落とす → 線を選ぶ）→ 手順 2（公図を自動で取得 → 同意 → 取得）→ 手順 3（タイル → 一覧の行 → 地図を寄せる）→ 手順 4（判定する → 色づく → 区切りの詳細）→ 手順 5（直す）→ 手順 6（距離標 2 本）→ 手順 7（CSV・PDF・KML を書き出す）

- 判定の待ち時間（8 窓で 1〜2 分）は、色づく所を 10 秒ほど残して詰める。記録（log）の数字（秒・$）は 1 行だけ読めるように止める
- 地図を寄せるときはマウスのホイールでなく「+」ボタンで 1 段ずつ（滑らかに映る）

### 編集

- 1920×1080、30fps。字幕は画面の下に白地の帯、1 行 20 字まで
- 道具の画面は切り抜かず全体を映す（パネルと地図の関係が分かるように）。寄せるときは編集でなく道具の操作で
- 最後の出典は 6 秒以上止める

## 映像の素材（他人のもの）

**動画のファイルはリポジトリに入れない。** 大きいうえに他人の著作物なので、手元の作業用のフォルダに置く。使う前に、ライセンスをもう一度ページで確かめる（変わることがある）。

主催者は提出した動画を宣伝などに使うことがあり、そのときクレジットが外れるおそれがある。だから**表示が要らない素材（Pexels・CC0）を優先**し、CC BY-SA（できた動画にも同じライセンスが及びうる）はなるべく避ける。
